# Portable R57 / Run50 evidence

This small bundle supports the [R57 report](../../revision57_validation.md). Run50 completed delivery and measured HOME in **14 min 15.558 s**, one verified trial with 44.442 seconds of headroom. The book dropped into the bin; settled containment does not establish gentle handling, repeatability or competition readiness. Archived Run50 and its owned processes are closed; this record does not describe any later GUI demonstration.

These eleven evidence files are byte-for-byte copies of existing local records. The [copy manifest](manifest.json) records their original paths, sizes and SHA-256 values. Repository attributes disable line-ending conversion in this directory so checkout preserves the recorded evidence bytes. Embedded absolute paths and references to unbundled files are **local-archive provenance**, not working GitHub links. The original geometry Markdown is preserved as plain text so its local links are not presented as navigable repository links.
